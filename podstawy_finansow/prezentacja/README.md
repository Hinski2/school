# deficyt budżetu państwa vs deficyt całego sektora
możemy liczyć deficyt na 2 sposoby:

| | deficyt budżetu państwa | Deficyt sektora general government |
| --- | --- | --- |
| co obejmuje | tylko budżet państwa (ministerstwa wydatki z ustawy budżetowej) | budżet państwa + samorządy + ZUS/FUS  + NFS + fundusze zarządzane przez BGK | 
| kto używa który budżet | MF w ustawie budżetowej | GUS i Eurostat | 
| 2025 | 275.6 mld zł | ~284 mld zł |
